# The impulse responses Tangent ships

Three captures of an Alesis Quadraverb, made by the owner of this app with
Tangent's own IR wizard on 2026-09-05, so that the IR unit is not an empty
browser on a fresh install. They are compiled into the binary
(`tangent/src/ir_pack.rs`) and written to the user's `IRs` folder once, the
first time the shelf is scanned; a file the user deletes stays deleted.

| File | Program captured | Length |
| --- | --- | --- |
| `HOLMES'PLATE (ALESIS QUADRAVERB).wav` | Holmes' Plate | 1.66 s |
| `KINGS CHAMBER (ALESIS QUADRAVERB).wav` | Kings Chamber | 2.48 s |
| `TAJ MAHAL modw (ALESIS QUADRAVERB).wav` | Taj Mahal, modulation wide | 3.36 s |

All three are 44.1 kHz, stereo, 32-bit float WAV, as the wizard writes them.
